## Use cases by role

The course's closing lessons are organized by function rather than by
feature — a reminder that the same handful of tools show up differently
depending on the job:

- **General/cross-role** — status reports, extracting patterns from
  customer feedback, packaging brand guidelines as a reusable Skill.
- **Sales** — competitive battle cards, deal prep and prospect research,
  turning pipeline data into reports.
- **Marketing** — campaign performance analysis, repurposing content
  across channels.
- **Finance** — building financial models, drafting investment memos,
  decoding an inherited spreadsheet.
- **HR** — role-tailored onboarding guides.
- **Legal** — discovery timeline tracking and pattern analysis across case
  documents.
- **Research** — planning literature reviews, verifying statistics against
  raw data.

The exercise worth actually doing: don't just read the examples above —
work out which two or three map onto your real week, since that's the gap
between finishing a course and changing how you work.

## Beyond claude.ai: the rest of the product surface

The course closes by mapping Claude onto the specific places work already
happens, each suited to a different job:

| Tool | Best for | Where it runs |
|---|---|---|
| Claude.ai | General tasks, research, writing, file creation | Web, desktop, mobile |
| Claude Code | Software development, codebase navigation, git workflows | Terminal, IDE, or browser |
| Claude Cowork | Sustained multi-step work: research briefs, document assembly, file organization | Desktop (+ mobile via Dispatch) |
| @Claude | Team collaboration, meeting prep, quick in-context answers | Slack |
| Claude Design | UI prototypes and design exploration | Web |
| Claude for Microsoft 365 | Editing in place, carrying context across a document | Excel, PowerPoint, Word, Outlook sidebars |
| Claude in Chrome | Web research, inbox help, browser automation | Chrome sidebar (public beta) |

Two worth flagging specifically: **Claude Code** is the natural next step
for anything touching a real codebase — the subject this repository's own
teaching deck (*Claude Code, Taught*) covers in far more depth, and this
learning path's own Tier 2. **Claude in Chrome** is explicitly public beta
— Anthropic's own guidance is to use it for low-risk tasks on trusted
sites; it asks permission before higher-risk actions like purchases, and
blocks certain site categories (financial services, adult content) by
default.

## What the course actually covered (its own recap)

- **Getting started** — Claude as a helpful, honest, harmless thinking
  partner, accessible everywhere, with prompts built from stage, task, and
  rules.
- **Getting better results** — iteration over one-shot perfection, fixing
  common failure patterns with more specific context, and the 4D Framework
  (Delegation, Description, Discernment, Diligence) as the underlying
  discipline (see Tier 0 of this path for the full course on it).
- **Organizing your work** — Projects for persistent knowledge, Artifacts
  for standalone outputs, Skills for repeatable procedures.
- **Expanding Claude's reach** — Connectors (built on MCP) linking real
  tools, Enterprise Search across a whole organization, Research for deep
  multi-source investigation.
- **Putting it together** — the same handful of features, reshaped by role
  and by product surface.
