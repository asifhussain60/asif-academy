# Orientation — How to Use This Learning Set

## What this is

This is a companion learning set for Anthropic's free **Claude 101** course
(hosted on Skilljar: https://anthropic.skilljar.com/claude-101). Claude 101 is
Anthropic's own foundational course, built because most people who use Claude
only ever use the basic chat window — they never touch Projects, Artifacts,
Skills, Connectors, Enterprise Search, or Research mode. The course exists to
close that gap in about 2–3 hours, and it ends with a real certificate of
completion.

**Important honesty note:** Skilljar gates the actual lesson videos and text
behind free registration. These seven documents are **not** a copy of that
paywalled content. They are built from Anthropic's own public documentation,
help-center articles, and Anthropic Academy's public companion YouTube videos
(confirmed real links, not guessed ones). Treat this folder as a structured
*pre-read and study companion* — you should still register for the free
course at the link above and go through the actual lessons, especially the
parts these documents flag as "not independently confirmed."

## Why these documents are split the way they are

Claude 101 is organized into four official modules:

1. **Meet Claude** — what Claude is, your first conversation, getting better results
2. **Organizing your work and knowledge** — Projects, Artifacts, Skills
3. **Expanding Claude's reach** — Tools, Connectors, Enterprise Search, Research mode
4. **Putting it all together** — role-based use cases, what's next, certificate

Each module gets its own document (01 through 04), because loading Google
NotebookLM with one large document tends to produce a single flat overview.
Loading it with several focused, sequential documents lets it generate a
cleaner slide deck or audio overview *per topic*, and lets you stop and absorb
one module before the next one adds new vocabulary on top of it.

## This is Tier 1 of a five-tier path

This folder is one notebook's worth of material inside a larger learning
path that covers the whole Anthropic Academy catalog, organized around
becoming a Claude Code expert. See [`../00-INDEX.md`](../00-INDEX.md) for the
full roadmap and [`../NOTEBOOKLM-GUIDE.md`](../NOTEBOOKLM-GUIDE.md) for how to
load every tier into Google NotebookLM correctly — that guide is shared
across all five tiers rather than repeated in each one.

## What you'll be able to do after finishing this set

- Explain, in your own words, the difference between a chat, a Project, an
  Artifact, and a Skill — and know instantly which one a given task needs.
- Turn on and use Connectors, Enterprise Search, and Research mode when a
  task needs information Claude doesn't already have.
- Recognize which of Claude's features fits your own role's day-to-day work.
- Use NotebookLM itself as a study tool — not just for this material, but for
  future learning sets you build the same way.
