## Curriculum

Studio currently offers: Audio Overview, Slide deck, Video Overview, Mind
Map, Reports, Flashcards, Quiz, Infographic, Data table. As a visual
learner, lead with Mind Map/Slide deck/Infographic/Video Overview; treat
Audio Overview as an optional, last, commute-time pass.

Before each generation, check only the sources listed in **Sources
checked** in the left-hand Sources panel (uncheck the rest) — this scopes
that specific output to just those documents instead of the whole notebook.
The 6 YouTube videos count as sources too once added — include them
wherever "All" is listed.

| Session | Read | Sources checked | Generate |
|---|---|---|---|
| 1 | `00-orientation.md` + `01-meet-claude.md` | All, then Only `01-meet-claude.md` | **Mind Map** for the whole notebook, then a **Slide deck** for Chat/Cowork/Code and the prompting framework |
| 2 | `02-organizing-work.md` | Only `02-organizing-work.md` | **Slide deck** — Projects vs. Artifacts vs. Skills |

## Prompts to enter in Studio's "Customise" dialog

The **Infographic** dialog has extra controls beyond the description box —
Language, Orientation, Visual style, and Level of detail. Recommended
settings are given with that infographic below; leave Language on
**English**.

**Session 1 — Mind Map**
> Show how Chat, Cowork, and Code relate to each other, and how the three-part prompting framework (setting the stage, defining the task, specifying rules) applies across all three.

**Session 1 — Slide deck**
> Create a slide deck on Chat vs. Cowork vs. Code and the three-part prompting framework — setting the stage, defining the task, specifying rules — with one worked example prompt.

**Session 2 — Slide deck**
> Create a slide deck comparing Projects, Artifacts, and Skills — what each one stores, when to reach for it, and how they combine with each other.

**Session 3 — Slide deck**
> Create a slide deck on Connectors (and the Model Context Protocol behind them), Enterprise Search, and Research mode — what each does and when to use it instead of the others.

**Session 4 — Slide deck**
> Create a slide deck of Claude use cases organized by role — sales, marketing, finance, HR, legal, research — plus the non-claude.ai surfaces: Claude Code, @Claude, Claude Design, Claude for Microsoft 365, and Claude in Chrome.

**Session 5 — Infographic**
> Orientation: **Portrait** (this is a printable reference card, not a wide comparison). Visual style: **Sketch note**. Level of detail: **Detailed** (every glossary term needs to survive — this is meant to replace the cheatsheet, not tease it).
>
> Describe the infographic: Turn this glossary and feature-selection cheatsheet into a single visual reference card — one column of terms with plain-English definitions, one column of "when to use it."

**Session 6 — Video Overview**
> Recap this whole notebook — Chat/Cowork/Code, Projects/Artifacts/Skills, Connectors/Enterprise Search/Research mode, and role-based use cases.

**Session 6 — Flashcards**
> Make flashcards from the glossary and feature-selection cheatsheet terms in this notebook — term on the front, plain-English definition on the back.

**Session 6 — Quiz**
> Quiz me on the feature-selection cheatsheet — given a task description, which Claude feature (Chat, Project, Artifact, Skill, Connector, Enterprise Search, Research) fits best.
